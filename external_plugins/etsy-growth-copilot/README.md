# Etsy Growth Copilot

Store-agnostic skills for an Etsy seller: listing SEO, product validation, launch and store-audit checklists, Etsy Ads break-even planning and weekly review, sales tracking, and a growth plan.

The plugin never publishes a listing, changes a price, or spends money without the owner's explicit approval.

A companion Grok Bot template is available at <https://x.ai/bot/NwUn4nWYCGthWcPTPfnLn>.

## Installation

In Grok Build, open `/plugin`, search for **Etsy Growth Copilot**, and install.

## Skills

| Skill | Use it for |
|---|---|
| `etsy-core-rules` | Shared Etsy limits, fees, shipping, ads math, review ethics, and the approval rule |
| `listing-seo-pack` | Title, 13 tags, description, attributes, and photo alt text |
| `product-validation` | Go / test / kill scorecard for a new product idea |
| `launch-checklist` | Field-by-field check before the owner approves a publish |
| `store-audit` | Featured items, sections, headline, announcement, About, banner, stale listings |
| `ads-plan-and-weekly-review` | Break-even math, budget steps, and the Monday ads review |
| `sales-tracker` | Weekly Stats snapshot and SEO refresh triggers |
| `growth-plan` | Milestones, seasonal calendar, and 30- and 90-day reviews |

## How it works

Skills only. There is no MCP server, no hooks, and no stored credentials. Work from what the owner provides: product facts, a spreadsheet they choose, or screenshots of their own signed-in Etsy Stats. If Etsy blocks automated access, stop and ask for screenshots.

Fee, ads, and shipping figures in the skills are reference facts. Re-verify them on Etsy before quoting them as current. The seller's own numbers override any benchmark.
