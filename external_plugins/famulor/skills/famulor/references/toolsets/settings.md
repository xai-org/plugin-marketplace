# Settings toolset

Account, workspaces, API keys, retention, memory, domains, and sessions. Connect only this group with `https://app.famulor.io/mcp?toolsets=settings`.

This 2026-10-08 snapshot covers all 38 tools assigned to `settings` in the canonical 439-tool registry. The live MCP `tools/list` response is authoritative for arguments, current availability, annotations, and plan or role gating. Never invent fields from this catalog.

Toolsets limit discovery context; they do not grant access. OAuth/API scopes and workspace roles are enforced separately. The Effect column reflects MCP risk annotations: `Delete/destructive` also covers overwrites or changes that can remove data or safeguards.

**Caution:** API-key revocation, session sign-out, domain removal, retention changes, and ownership transfer can disrupt access or remove data. Confirm the exact account, workspace, and irreversible impact first.

| Tool | Effect | Accepted scope | Execution | Purpose snapshot |
| --- | --- | --- | --- | --- |
| `add_custom_domain` | Write/action | `settings:write or assistants:write` | Immediate | Attach a hostname to the workspace's Vercel project. The response contains ownership and routing DNS records; the hostname is not activated until ownership, DNS, and TLS are ready. |
| `create_api_key` | Write/action | `settings:write` | Immediate | Mint a new workspace API key. scopes must be a subset of THIS credential's own scopes — a key can never mint another key with broader access than itself (omitted = same scopes as this credential, or every scope if this credential already has full access). A new key cannot outlive a finite calling credential. The plaintext key is returned exactly once and is never stored or shown again. |
| `create_support_request` | Write/action | `settings:write` | Immediate | Submit a support request for this root workspace, including a white-label reseller workspace. The client_request_id makes retries idempotent. This tool is unavailable to reseller-customer workspaces. |
| `create_workspace` | Write/action | `settings:write` | Immediate | Create an ADDITIONAL workspace owned by this credential's user. Requires a user-owned API key or OAuth token — a service-account key IS a single workspace and cannot own more (fails with a clear error). Gated by the plan's max_workspaces limit (-1 = unlimited, 0 = feature off) plus the extra_workspaces capacity add-on, evaluated across every workspace this user already owns in this same brand; fails once that allowance is exhausted. |
| `create_workspace_api_key` | Write/action | `settings:write` | Immediate | Mint a service-account API key for a selected workspace in which this credential's user is currently an owner or admin. Requires a user-owned API key or OAuth token and does not require white-label access. The target must be visible within this credential's brand. scopes can only stay equal to or become narrower than this credential's own scopes. The plaintext key is returned exactly once. |
| `delete_passkey` | Delete/destructive | `settings:write` | Immediate | Remove one of the user's passkeys by the id returned by list_passkeys, e.g. for a lost device. The user can no longer sign in with it; other sign-in methods keep working. Only available on the main platform and with a user-owned API key or OAuth token. |
| `get_ai_inference_settings` | Read-only | `settings:read` | Immediate | Read the workspace AI inference region (global, eu, or us). EU also activates after-save AI-disclosure review for assistants. |
| `get_consent_mode` | Read-only | `settings:read or assistants:read` | Immediate | Read how marketing opt-outs are enforced in this workspace. universal suppresses every linked channel after any opt-out; per_channel suppresses only the channel where the opt-out was received. |
| `get_credit_notification_preferences` | Read-only | `settings:read` | Immediate | Read the personal low-credit warning threshold and delivery channels for the user associated with this credential. The preference follows the user across workspaces and requires a user-owned API key or OAuth token. |
| `get_custom_domain` | Read-only | `settings:read or assistants:read` | Immediate | Read the workspace custom domain and its live Vercel ownership, DNS routing, and TLS readiness. Returns the exact TXT/A/CNAME records still required. |
| `get_dark_window_settings` | Read-only | `settings:read or assistants:read` | Immediate | Read proactive-outbound quiet hours for every supported channel. Times use the workspace timezone; inbound customer replies remain available. |
| `get_marketing_integrations` | Read-only | `settings:read or assistants:read` | Immediate | Read structured marketing pixel IDs (GA4, Meta, Google Ads, Microsoft UET) for this white-label domain. Conversion API secrets are never returned — only whether a secret is stored. |
| `get_me` | Read-only | `None` | Immediate | Inspect the calling credential: API key / token metadata, tenant, active plan, effective limits, feature toggles, and Assistant engine-mode availability (-1 = unlimited, 0 = disabled). Requires no scope — works with any valid token. plan.*_cents amounts are EUR (canonical); display_currency + display_currency_rate describe the workspace's resolved presentation currency. |
| `get_memory_settings` | Read-only | `settings:read or assistants:read` | Immediate | Read workspace memory defaults, available channels, consent, staleness and retention. Web Chat and Web Voice are configured separately. Web and SMS memory are available only to root workspaces. |
| `get_outbound_limits` | Read-only | `settings:read or assistants:read` | Immediate | Read the workspace-wide daily quota, today's usage, remaining calls, reset time, and increase-request status for outbound calls through integrated numbers. Inbound, web, and customer-owned SIP trunk calls are unlimited. |
| `get_retention_settings` | Read-only | `settings:read or assistants:read` | Immediate | Read per-channel workspace retention overrides, governing limits, the plan entitlement, and the exact plan default in days. A null channel value follows the plan default. |
| `get_support_request` | Read-only | `settings:read` | Immediate | Get one of your support requests by its reference (SUP-…) with status, assigned team member and the full conversation with the support team. |
| `get_workspace_country` | Read-only | `settings:read` | Immediate | Read the workspace home country as an ISO-3166-1 alpha-2 code. Null means it has not yet been detected or selected. |
| `list_account_sessions` | Read-only | `settings:read or assistants:read` | Immediate | List the browsers and devices with tracked active sign-in sessions for the user associated with this credential. Authentication tokens and IP addresses are never returned. |
| `list_api_keys` | Read-only | `settings:read` | Immediate | List the workspace's API keys, including revoked ones (see revoked_at). The secret is never returned — only id, name, prefix, scopes, and usage timestamps. |
| `list_passkeys` | Read-only | `settings:read` | Immediate | List the passkeys the credential's user can sign in with: authenticator name, when each was added and last used. Only available on the main platform and with a user-owned API key or OAuth token. Passkeys are added in the app under Settings → Preferences, because that needs the user's device. |
| `list_support_requests` | Read-only | `settings:read` | Immediate | List your own support requests in this workspace (newest first, max 30) with status (open, on_hold, resolved), priority, the assigned support team member's name and the number of unread replies. Unavailable to reseller-customer workspaces. |
| `list_workspaces` | Read-only | `settings:read` | Immediate | List the workspaces visible to this credential. For a user-owned API key or OAuth token, every workspace the key owner is a member of within THIS key's own brand — the key's own tenant is flagged current: true. A service-account key is a single workspace by construction and only lists itself. Switching the active workspace is per-credential (use or mint a key/token bound to the target workspace) — this tool only lists what is visible, it never switches. See create_workspace for the plan-gated limit on how many additional workspaces a user may own. |
| `remove_custom_domain` | Delete/destructive | `settings:write or assistants:write` | Immediate | Detach the workspace custom domain from Vercel and disable it for host-based login and branding. |
| `reply_to_support_request` | Write/action | `settings:write` | Immediate | Send a reply to the support team on one of your support requests. Replying to a resolved request reopens it. Do not include passwords, access tokens, or payment data. |
| `request_outbound_limit_increase` | Write/action | `settings:write or assistants:write` | Immediate | Submit a workspace-wide increase request for integrated outbound calls. Only workspace owners and admins can request a change. |
| `revoke_api_key` | Delete/destructive | `settings:write` | Immediate | Soft-revoke an API key. Idempotent — revoking an already-revoked key still returns { revoked: true }. A key may revoke itself. |
| `set_consent_mode` | Delete/destructive | `settings:write or assistants:write` | Immediate | Set workspace marketing opt-out enforcement to universal or per_channel. Per-channel mode requires the Consent & Compliance plan feature; suppression enforcement itself is always active. |
| `sign_out_account_session` | Delete/destructive | `settings:write or assistants:write` | Immediate | Revoke one active device session by the opaque id returned by list_account_sessions. |
| `transfer_workspace_ownership` | Delete/destructive | `settings:write` | Immediate | Make an existing active, verified member the workspace owner. Requires a user-owned credential belonging to the current owner. The previous owner becomes an admin; plan, credits, payment details and workspace data stay in place. The previous owner’s personal API keys and OAuth access for this workspace are revoked. Read the current owner and target membership with list_team_members before confirming this action. |
| `update_ai_inference_settings` | Write/action | `settings:write` | Immediate | Update the workspace AI inference region. Values: global (default), eu, or us. Changing the region re-reviews existing assistants; EU requires a clear AI introduction in the effective opening. |
| `update_credit_notification_preferences` | Write/action | `settings:write` | Immediate | Update the personal low-credit warning threshold and delivery channels for the user associated with this credential. Enable at least one delivery channel when warnings are enabled. The preference follows the user across workspaces and requires a user-owned API key or OAuth token. |
| `update_dark_window_settings` | Write/action | `settings:write or assistants:write` | Immediate | Update proactive-outbound quiet hours for one or more channels. Omitted channels stay unchanged; overnight windows use a start later than the end, for example 21:00 to 08:00. |
| `update_marketing_integrations` | Write/action | `settings:write or assistants:write` | Immediate | Merge marketing pixel IDs and optional conversion-API secrets for this white-label domain. Omit a secret to keep the stored value. Requires white-label access. Never send platform pixels to a customer domain. |
| `update_memory_settings` | Write/action | `settings:write or assistants:write` | Immediate | Update consent-aware cross-channel customer-memory defaults. Assistants with memory_mode 'inherit' follow memory_enabled_default; 'on'/'off' override it per assistant (update_assistant). |
| `update_retention_settings` | Delete/destructive | `settings:write or assistants:write` | Immediate | Update one or more per-channel retention periods in months. Set a channel to null to restore the plan default. Requires the Data Retention feature in the workspace plan. |
| `update_workspace_country` | Write/action | `settings:write` | Immediate | Set the workspace home country using an ISO-3166-1 alpha-2 code. Pass null to use automatic location detection on the next dashboard or sign-in request. |
| `verify_custom_domain` | Write/action | `settings:write or assistants:write` | Immediate | Ask Vercel to recheck the workspace custom-domain ownership challenge and current DNS/TLS configuration. |
