# Messaging toolset

Messaging, email, connected channels, templates, and sender profiles. Connect only this group with `https://app.famulor.io/mcp?toolsets=messaging`.

This 2026-10-08 snapshot covers all 46 tools assigned to `messaging` in the canonical 439-tool registry. The live MCP `tools/list` response is authoritative for arguments, current availability, annotations, and plan or role gating. Never invent fields from this catalog.

Toolsets limit discovery context; they do not grant access. OAuth/API scopes and workspace roles are enforced separately. The Effect column reflects MCP risk annotations: `Delete/destructive` also covers overwrites or changes that can remove data or safeguards.

**Caution:** Sending messages or disconnecting channels has real external effects. Deleting a domain removes its addresses; deleting a synced template may affect its provider copy. Confirm the recipient or resource before execution.
