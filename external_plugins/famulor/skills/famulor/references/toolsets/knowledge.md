# Knowledge toolset

Knowledge bases, documents, FAQs, websites, and connected drives. Connect only this group with `https://app.famulor.io/mcp?toolsets=knowledge`.

This 2026-10-08 snapshot covers all 26 tools assigned to `knowledge` in the canonical 439-tool registry. The live MCP `tools/list` response is authoritative for arguments, current availability, annotations, and plan or role gating. Never invent fields from this catalog.

Toolsets limit discovery context; they do not grant access. OAuth/API scopes and workspace roles are enforced separately. The Effect column reflects MCP risk annotations: `Delete/destructive` also covers overwrites or changes that can remove data or safeguards.

**Caution:** Crawls and drive syncs can consume credits; deleting sources or documents may remove indexed content. Review source and cost before running or deleting.

| Tool | Effect | Accepted scope | Execution | Purpose snapshot |
| --- | --- | --- | --- | --- |
| `add_document` | Write/action | `knowledge:write or assistants:write` | Immediate | Add and index a document using exactly one of 'content' (raw text; 'name' required) or 'url' (file URL, max 20 MB). Alternatively, provide 'document_id' alone to retry an existing document synchronously. Retry returns document_id, chunk_count, total_chunks and truncated. Cloud drive retries refresh only that file from its current source, charge normal sync credits, preserve the previous index on failure and require the same feature access and sync lock as the UI. Other sources retry their retained file or website. Creation returns the final document with status 'ready' or 'error'. |
| `create_crawl_source` | Write/action | `knowledge:write or assistants:write` | Immediate | Register a website with an optional custom source name as a crawl source for a knowledge base. When omitted, the name defaults to 'root_url'. The crawler fetches pages under 'root_url' (same host only), indexes them as documents, and charges credits per crawled page. Trigger a crawl with run_crawl_source, or enable 'auto_sync' for periodic re-crawls. No JavaScript rendering — only static HTML is read. |
| `create_drive_source` | Write/action | `knowledge:write or assistants:write` | Immediate | Register a Google Drive, OneDrive, Box, Dropbox, or SharePoint folder with an optional custom source name, using an existing app connection (Automations → Connections). When omitted, the name defaults to 'folder_name' or 'folder_id'. The sync lists files under 'folder_id' (optionally recursive), indexes them as documents, and charges credits per new/changed file. Trigger a sync with run_drive_source, or enable 'auto_sync' for periodic re-syncs. SharePoint sources also require 'drive_id' (the target document library). |
| `create_faq_entry` | Write/action | `knowledge:write or assistants:write` | Immediate | Create a human-authored question and answer and immediately index it as approved knowledge. |
| `create_knowledge_base` | Write/action | `knowledge:write or assistants:write` | Immediate | Create a new (empty) knowledge base. Add content with add_document, then attach it to an assistant via its knowledgebase_id field. |
| `delete_crawl_source` | Delete/destructive | `knowledge:write or assistants:write` | Immediate | Delete a website crawl source. Documents already created by past crawls are kept; only future syncs stop. |
| `delete_documents` | Delete/destructive | `knowledge:write or assistants:write` | Immediate | Delete one or more documents (up to 200) from a knowledge base, together with their indexed chunks and stored original files; document ids come from list_knowledge_documents. Assistants stop using the content right away. Unknown or already deleted ids are returned in not_found_ids. Pages from an Auto Refresh website come back on the next refresh unless they are added to its exclude paths; files from a cloud drive come back on the next sync unless they are removed from the synced folder. |
| `delete_drive_source` | Delete/destructive | `knowledge:write or assistants:write` | Immediate | Delete a cloud drive sync source. Documents already created by past syncs are kept by default; only future syncs stop. Set 'purge_documents' to also remove the documents this source already created. |
| `delete_faq_entry` | Delete/destructive | `knowledge:write or assistants:write` | Immediate | Delete one FAQ entry, its occurrences, and its retrieval embedding. |
| `delete_knowledge_base` | Delete/destructive | `knowledge:write or assistants:write` | Immediate | Delete a knowledge base including all its documents and embeddings. This cannot be undone. |
| `discover_crawl_source_paths` | Read-only | `knowledge:read or assistants:read` | Immediate | Inspect a website's same-host crawl paths before creating or updating a source. Uses robots.txt and sitemaps when available, creates no source or documents, and spends no credits. |
| `get_faq_entry` | Read-only | `knowledge:read or assistants:read` | Immediate | Fetch one FAQ entry with its recent knowledge-gap occurrences. |
| `get_knowledge_base` | Read-only | `knowledge:read or assistants:read` | Immediate | Fetch a single knowledge base by ID (name, description, document count). |
| `list_crawl_source_pages` | Read-only | `knowledge:read or assistants:read` | Immediate | List the ready website pages already indexed for one crawl source. This read-only lookup does not fetch the website, start a refresh, or spend credits. |
| `list_crawl_sources` | Read-only | `knowledge:read or assistants:read` | Immediate | List the named website crawl sources of a knowledge base (each source crawls pages under a root URL into documents). |
| `list_document_chunks` | Read-only | `knowledge:read or assistants:read` | Immediate | List the indexed, searchable chunks of one knowledge-base document in source order (document ids come from list_knowledge_documents). Returns chunk text and token estimates; embeddings and internal metadata are never exposed. |
| `list_drive_sources` | Read-only | `knowledge:read or assistants:read` | Immediate | List the named cloud drive sync sources of a knowledge base (each source syncs files from a Google Drive, OneDrive, Box, Dropbox, or SharePoint folder into documents). |
| `list_faq_entries` | Read-only | `knowledge:read or assistants:read` | Immediate | List and search FAQ entries or knowledge gaps for one knowledge base. Search matches questions, answers and proposed answers before pagination. Total counts matching entries; pending counts all open entries regardless of filters. Agent-generated answers remain drafts until explicitly approved. |
| `list_knowledge_bases` | Read-only | `knowledge:read or assistants:read` | Immediate | List the account's knowledge bases (RAG document collections that assistants can search during calls). |
| `list_knowledge_documents` | Read-only | `knowledge:read or assistants:read` | Immediate | List the documents of one knowledge base, newest first, with source type, indexing status (processing, ready or error with error_message) and chunk count. Covers uploads, text, file URLs, websites, crawled pages and cloud drive files. Use a document id with list_document_chunks or add_document (retry). |
| `run_crawl_source` | Write/action | `knowledge:write or assistants:write` | Immediate | Crawl a website source now (synchronous). Fetches pages under the root URL, re-indexes changed pages (unchanged pages are skipped via content hash — no re-embedding, no credits), and charges credits per new or changed page. Error pages and pages without readable content are skipped and never replace an indexed page. Aborts gracefully if the account runs out of credits (partial results kept). Returns pages_crawled, pages_skipped, credits_spent and status. |
| `run_drive_source` | Write/action | `knowledge:write or assistants:write` | Immediate | Sync a cloud drive source now (synchronous). Lists files under the folder (optionally recursive), re-indexes new/changed files (unchanged files are skipped via content hash — no re-embedding, no credits), removes documents whose file no longer exists in the folder, and charges credits per new/changed file. Aborts gracefully if the account runs out of credits (partial results kept). Returns files_synced, files_unchanged, files_deleted, files_failed, files_skipped_unsupported, credits_spent and status. |
| `search_knowledge_base` | Read-only | `knowledge:read or assistants:read` | Immediate | Find document excerpts or exact table values with source references. Use table_query with discovered document, sheet and column keys for complete-table filters or count/sum/min/max; never total search excerpts. Cached formulas are unverified and similar identifiers must not replace missing values. |
| `update_crawl_source` | Write/action | `knowledge:write or assistants:write` | Immediate | Update a website crawl source (custom name, root URL, include/exclude paths, page limit, auto-sync settings). |
| `update_drive_source` | Write/action | `knowledge:write or assistants:write` | Immediate | Update a cloud drive sync source (custom name, app connection, folder, subfolder recursion, file limit, auto-sync settings). |
| `update_faq_entry` | Write/action | `knowledge:write or assistants:write` | Immediate | Edit a FAQ or knowledge-gap draft and set its review status. Approval requires a non-empty answer and publishes it to retrieval. |
