---
name: aurea77-setup
description: Help an athlete connect their own Aurea77 account and choose a sporting-event task after installing Aurea77.
---

Use the plugin's OAuth connection flow to link the athlete's own Aurea77 account. Never request a password, access/refresh token, booking reference, identity document or medical file in chat. Let the user review Aurea77's consent screen. Existing read consent does not authorize writes; ask for only the tool permissions needed for the user's chosen task.

Read the connected profile after linking and confirm which account is connected without displaying unnecessary personal details. Ask whether the athlete wants to record an existing external registration, prepare for an event, organize travel/accommodation, record a result, manage equipment, read awarded badges, read text posts or review insights. Continue an already stated task without repeating onboarding.

Explain that external registration records and race results are athlete reported. The integration does not submit organizer registrations, make bookings, take payments or certify official results. Do not promise unlimited Free-plan access or availability on an unverified platform.
