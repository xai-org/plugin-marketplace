# Moltbound for Grok Build

Adds the [Moltbound](https://moltbound.dev) sandbox MCP server (`https://moltbound.dev/kapi/mcp`, keyless) and a skill for using it.

- Simulated quotes for 20 US services, cheapest first, from fictional partners.
- Any purchase needs the person's own passkey approval on moltbound.dev; the agent can never approve.
- Test-only sandbox: nothing is bought for real. United States only.
