# Nolavi Connect plugin for Grok Build

Connect Grok Build to [Nolavi Connect](https://connect.nolavi.ai) and run your ads, website and
listings from your AI: Google Ads, Local Services, Analytics, Search Console, Business Profile,
Microsoft Ads, LinkedIn Ads, ChatGPT Ads and WordPress.

It reads campaigns, search terms, keywords with quality score, results and reviews, and it builds
and changes campaigns, ads, keywords, budgets (max 20% a step), locations, schedules, sitelinks and
landing pages. Every change waits for the owner's approval in the chat, and new campaigns start
paused.

## Installation

In Grok Build, open `/plugin`, search for **Nolavi Connect**, and install.

On first connection, Grok opens the Nolavi sign in in the browser. Nothing to install and no API
key to paste.

## Authentication

The plugin connects only to `https://connect.nolavi.ai/mcp` (streamable HTTP). Authentication is
OAuth 2.1 with PKCE against that host. No API key or token is stored in the plugin.
