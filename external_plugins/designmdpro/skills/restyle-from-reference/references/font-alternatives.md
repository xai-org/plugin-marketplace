# Free alternatives to commercial fonts

Use these when a reference site's font is commercial or brand-exclusive and the project has no license for it. Every alternative is free on Google Fonts. Font names are matched case-insensitively.

If a font is not listed, choose a free family with similar proportions (x-height, width, terminals) and tell the user it is your own pick.
