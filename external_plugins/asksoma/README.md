# Asksoma : Astrology Horoscope numerology

AskSoma's hosted MCP connector brings Vedic astrology, horoscope, Panchang, compatibility, and numerology tools to Grok Build.

The connector uses OAuth at `https://api.asksoma.ai/mcp`. Users authenticate with their AskSoma account. New accounts receive 10 complimentary lifetime MCP calls; a subscription is required for additional readings.

The plugin exposes AskSoma's public MCP tools, including Panchang readings, Kundli charts, compatibility, chart sessions, and plain-language astrology insights.
